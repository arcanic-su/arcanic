# Arcanic Launcher

Лаунчер визуального клиента Arcanic для Minecraft (Fabric 1.21.11). Лицензия - GNU GPL v3 с дополнительным условием:
указание авторов сохраняется (см. `NOTICE` и `LICENSE`).

Авторы: **tuffboy999** и **Va1der**.

## Что делает

1. Вход в аккаунт Arcanic через сайт. На диске лежит только токен сессии, зашифрованный Windows (DPAPI), пароль не
   хранится.
2. Скачивает клиент с `/api/v1/client`. ETag - SHA-256 файла: если клиент не менялся, ничего не качается.
3. Ставит Minecraft, Fabric, библиотеки, ассеты и нужную Java, сверяя хэши.
4. Кладёт клиент в `mods/` и запускает игру с токеном аккаунта, по нему работает синхронизация.
5. Моды и ресурспаки с Modrinth, CurseForge и PacksMC, аккаунты Microsoft и локальные, статус в Discord, «доктор»,
   который чинит сломанный запуск.

Если `arcanic.su` недоступен (например, из России), лаунчер ходит через `ru.arcanic.su`. Без сети он запускает
игру с клиентом из кэша, без синхронизации.

## Premium и админка

Всё решает сервер, а не лаунчер. Кто админ, задаётся только на сервере; каждый запрос админки и каждый Premium-файл
сервер проверяет по токену аккаунта. Кнопки админки в лаунчере - это просто интерфейс: собранный из исходников
лаунчер без админского аккаунта получит от сервера 403. Ключей, паролей и адресов управления сервером в этих
исходниках нет, серверного кода тоже.

## Сборка

| Что | Как |
|---|---|
| Лаунчер (`native/build/Arcanic.exe`) | `native\build.bat`, нужны Visual Studio Build Tools с C++ |
| Установщик (`dist/Arcanic-Setup.msi`) | `powershell -ExecutionPolicy Bypass -File native\installer\build-msi.ps1` |

Один exe на C++ (Win32, Direct2D/DirectWrite, WinHTTP, CNG), без сторонних библиотек. Шрифт Inter - SIL OFL 1.1
(`THIRD-PARTY.txt`). Настройки: `~/.arcanic/launcher.properties`, там же `base=` для своего сервера.

Arcanic не является официальным продуктом Minecraft и не связан с Mojang или Microsoft.
