# Microsoft-аккаунты в Arcanic

Client ID: `dacf11f1-b22d-4b0d-a837-5504fd8af781`.

## Что готово

- В нативном Arcanic.exe: меню аккаунтов → Microsoft → вход в браузере → автоматический возврат. Можно хранить до трёх Microsoft-аккаунтов, выбирать их и удалять.
- Перед запуском лицензионная сессия обновляется. Minecraft получает настоящий ник, UUID, access token и тип аккаунта `msa`. При ошибке входа запуск останавливается, без перехода в офлайн.
- В моде: «Аккаунты» → «Добавить Microsoft», выбор и удаление сохранённых аккаунтов. Переключаться можно после выхода из мира/сервера. Меняются игровые службы авторизации, профиль и ключи чата, а не только ник.
- Лаунчер и мод используют общее хранилище `%USERPROFILE%\.arcanic\microsoft-accounts.dat`, защищённое Windows DPAPI. Пароли не запрашиваются внутри Arcanic. Refresh-токены не передаются в игру, Arcanic API или логи.
- Мод содержит модуль входа Windows, поэтому меню работает и при запуске через другой лаунчер. Офлайн-профили сохранены. Поддержка Microsoft в этой сборке — Windows x64.

## Настройки приложения Microsoft

В Microsoft Entra открой Arcanic Launcher:

1. Supported account types: **Personal Microsoft accounts only** либо вариант, включающий личные аккаунты Microsoft. «Только моя организация» для Minecraft не подходит.
2. Authentication → Add a platform → **Mobile and desktop applications**.
3. Добавь redirect URI **`http://localhost`**. Сохрани настройки. Лаунчер выбирает свободный локальный порт автоматически; путь возврата — `/`.
4. Client secret создавать и встраивать не нужно. Используется браузерный Authorization Code Flow с PKCE S256 и проверкой `state`, а не device code flow.
5. Для нового приложения запроси доступ к Minecraft API: https://aka.ms/mce-reviewappid. Укажи client ID выше. Успешная регистрация в Entra сама по себе не подтверждает разрешение Minecraft API.

Документация Microsoft:
- https://learn.microsoft.com/en-us/entra/identity-platform/scenario-desktop-app-configuration
- https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow

## Как проверить

Запусти новый `Arcanic.exe`, войди в Arcanic как обычно и выбери Microsoft в меню аккаунтов. В браузере войди в аккаунт, на котором доступна Minecraft Java Edition. Вернись в Arcanic и дождись появления ника. Выбери его и нажми «Играть».

В игре открой «Аккаунты»: лицензионные профили из лаунчера появятся в списке. Для другого аккаунта нажми «Добавить Microsoft». Повторное нажатие кнопки во время входа отменяет операцию. Удаление убирает сохранённый вход на этом ПК; уже запущенная игровая сессия не отзывается.

Если Minecraft возвращает 403 на этапе входа, проверь одобрение приложения. Если Microsoft пишет об организации или redirect URI — проверь пункты 1–3. Если нет профиля Java, проверь владение игрой/подписку и создание профиля на minecraft.net.

## Сборки и публикация

- `Arcanic.exe` — обновлённый нативный лаунчер. Старая Java-версия лаунчера и MSI не обновлялись.
- `arcanicvisuals-1.6.7.jar` — обновлённый мод для Minecraft 1.21.11 + Fabric. Заменяет предыдущий jar этой версии, не устанавливай обе копии одновременно.
- Лаунчер скачивает зашифрованный мод с сервера Arcanic. Чтобы новое меню появилось у игроков при обычном запуске, нужно опубликовать **новую сборку мода** через существующий процесс упаковки и обновления сервера. Сервер и ключи шифрования в этой работе не менялись. До публикации сервер может выдавать прежний мод.
- При последующих изменениях `native/microsoft.h` сначала выполни `native/build.bat`, затем скопируй `native/build/Arcanic.exe` в `arcanicvisuals/src/main/resources/assets/arcanicvisuals/auth/ArcanicAuth.exe` и пересобери мод. Так обе части используют одинаковую авторизацию.

## Проверено

Нативная сборка C++ и сборка Fabric-мода прошли. Автоматические проверки: PKCE по RFC 7636, callback/state/отмена, цепочка Xbox → Minecraft на тестовых ответах, сохранение и удаление в DPAPI, защита вывода от утечки токенов, сохранение обновлённого refresh-токена при сбое сервисов, параметры запуска лицензионного профиля. Проверен обмен Java → модуль Windows через закрытый канал stdout.

Minecraft запущен в отдельной тестовой папке; проверки меню, офлайн-профилей и полного восстановления исходной сессии прошли. Снимок — `accounts-preview.png`.
